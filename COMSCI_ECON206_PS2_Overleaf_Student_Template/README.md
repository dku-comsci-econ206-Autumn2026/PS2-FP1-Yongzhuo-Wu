## Compile

In Overleaf, select `main.tex` as the main document and XeLaTeX as the compiler. With a local TeX installation, use `latexmk -xelatex main.tex`.

`figures/` contains the editable teaser and its PDF/SVG exports. `supporting-materials/` contains the original reflection, Studio screenshots, review forms, and written responses. The computation and my saved Colab run are in `Colab/`; the A0 poster is in `Poster/`; the self-contained demonstration is in `Hugging Face/`.
